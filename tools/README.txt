WoT Strats {version}

A World of Tanks strat reference for the loading screen: type a map name and see that map's slide
from each StratSketch strat you've added.

1. Unzip the whole folder somewhere you can write to (Documents, Desktop), then run "WoT Strats.exe".
   Windows may warn that it's from an unknown publisher: click More info, then Run anyway.
2. Click Strats... (top right), paste a StratSketch link, give it a name, press Add.
   The first import of a strat downloads the map images it uses, so it can take a minute.
3. Type a map name. Keys 1-9 switch strat, scroll zooms, drag pans, 0 fits.

Your strats and map images are saved in this folder (data, maps). To pick up changes after a strat's
author edits it, press the circular arrow next to it in Strats...

Needs Windows 10 or 11. World of Tanks strats only.
https://github.com/magetron/wot-strats
